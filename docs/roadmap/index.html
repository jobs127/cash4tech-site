Project roadmap · for Cash4Tech

Where this site is headed

What this demo covers today, and how it grows into the full Sell + Buy site from Timothy's requirements.

In this demo Next Owner only

Sell Your Tech In this demo

24 landing pages built from one template: category, then brand, then popular model (for example /sell/phones/, /sell/phones/iphone/, /sell/phones/iphone-15/). Each page has its own content: what affects the offer, how to prep that device, and model facts. Calls to action are Get Directions, Visit Our Store and Call Us, plus a sticky call/directions bar on phones. Copy says paid in cash, with no online quotes or mail-in. Adding a page means adding a few lines to content.py.

Buy Electronics In this demo

A matching page tree under /buy/ that reads products straight from Shopify through the read-only Storefront API. Each model page shows every in-stock unit of that model (three iPhone 15s are three cards, each with its own photos). There's search, a product page with the device's real photos, and the 30-day return terms. Until the Storefront token is added, the pages show labeled sample cards.

Before launch Next

Connect the Storefront token and match each page's product search to the ERP's actual product types, vendors and tags. Fill in every ⚑ (address, hours, policies, shipping), swap in the real logo, set up GA4, Tag Manager and Search Console with call and directions tracking, then point getcash4tech.com here in Cloudflare without touching the Gmail MX, SPF, DKIM or DMARC records.

Online checkout Owner only

The product page already has a switch for an Add to cart button that hands off to Shopify's own checkout. It stays off until Timothy activates payments and approves shipping and tax settings. Nothing on this site turns on payment processing.

Growth Later

Hundreds more model pages, ad landing pages for searches like "sell iPhone Kansas City", real Google reviews, and more marketplaces through the ERP.

How the pieces fit

The ERP stays in charge of inventory and already publishes to Shopify. The website only reads from Shopify. It never changes inventory or touches the ERP.
